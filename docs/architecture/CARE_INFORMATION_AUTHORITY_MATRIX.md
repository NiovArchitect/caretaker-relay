# Care Information Authority Matrix

**Purpose:** Domain-specific authority — not a simplistic role hierarchy.

| Information type | Family caregiver | DSP / professional | Physician / NP | Recipient (when participating) |
|------------------|------------------|--------------------|----------------|--------------------------------|
| Personal observation (mood, meal, sleep) | REPORT, VIEW, CORRECT own | REPORT, VIEW | VIEW | REPORT, VIEW own |
| Medication administration report | REPORT (HITL confirm) | REPORT (HITL confirm) | VIEW, REQUEST CLARIFICATION | VIEW as allowed |
| Medication regimen / dose instruction | VIEW | VIEW | AUTHOR, CONFIRM | VIEW as allowed |
| Confirmed diagnosis | VIEW | VIEW limited | AUTHOR, CONFIRM | VIEW as allowed |
| Preferences / routine | REPORT, VIEW | VIEW, REPORT support notes | VIEW | AUTHOR, CORRECT |
| Appointments (lab honesty) | REQUEST, VIEW | VIEW | VIEW | VIEW |
| Handoff / coverage | REPORT, VIEW | REPORT, VIEW | VIEW | VIEW as allowed |
| Care coordination messages | SEND, VIEW circle | SEND, VIEW circle | SEND clinical when in team | SEND as allowed |
| Care notes / documentation | CREATE own role kind | CREATE support notes | CREATE provider updates | CREATE as allowed |
| Share outside care space | NO (default) | NO | Within clinical rules | Per authorization |

**Legend:** REPORT = create reported evidence · AUTHOR = create authoritative clinical source · CONFIRM = elevate truth · CORRECT = supersede with provenance · VIEW / SHARE as labeled.

**Rule:** Caregiver reports are valuable REPORTED evidence. They do not become diagnoses. Provider-authored clinical facts remain provider-authoritative within role and membership.
