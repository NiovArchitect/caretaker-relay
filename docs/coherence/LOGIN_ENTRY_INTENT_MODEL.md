# Login Entry Intent Model

**Date:** 2026-07-26

## Hierarchy

### PRIMARY

| Label | Supporting copy |
|-------|-----------------|
| **Sign in** | Return to care you already have access to |
| **Create account** | Create a private account with no care access |

### SECONDARY (Secure paths)

| Label | Supporting copy |
|-------|-----------------|
| **Accept invitation** | Use a secure invitation from an authorized person |
| **Set up care for someone new** | Create a new provisional care profile |

## Removed

- **Create & connect** / “New account — then request access” (overlapped Create account)

## Security promise (visible)

Access to someone’s care requires an invitation or approval.

## Distinction (5-second test)

- Sign in → existing access  
- Create account → no one’s care data  
- Accept invitation → specific circle via code  
- Someone new → provisional profile only, never match existing
