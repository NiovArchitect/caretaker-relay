# Experience Overhaul Contract (post-P0)

## Performance floor (non-negotiable)
- No hooks after early returns
- No nested backdrop-filter on scrolling sections
- Ambient animation off by default
- Polls ≥8–15s

## Visual direction
- Powder stage + teal ink retained as brand DNA
- Depth via tone, border, soft shadow — not GPU blur stacks
- Active states use accent fill + focus ring
- Live indicators restrained (single pulse max)

## Copy rules
- User action language first
- No “technical delivery”, no implementation chatter
- Safety once per consequential surface, not everywhere
- Empty states are paths, not apologies
