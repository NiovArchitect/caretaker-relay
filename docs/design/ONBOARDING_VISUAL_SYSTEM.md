# Onboarding Visual System

**Surfaces:** login entry cards · progressive wizard · lightweight empty care space  

**Principles**
- Progressive disclosure (one question group at a time)  
- Selected choice uses accent border + soft fill  
- Skip always available for nonessential steps  
- No medical form density  

**Components**
- `.login-entry-grid` / `.login-entry-card`  
- `.onboarding-wizard` / `.onboarding-choice`  
- Empty care space CTAs: Set up care · Add update · Handoff
