# ACL recipient & caregiver experience traceability

**Sources:** ACL Caregiver AI Challenge Track 1 judging criteria (user-centered design, dignity, choice, privacy, accessibility, burden reduction, human-in-the-loop, scheduling/transport/communication for older adults, people with disabilities, I/DD, ADRD).  
**Date:** 2026-07-27  
**Official reference:** https://acl.gov/caregiver-ai-judging-track1

## Populations

| Population | Caregiver Relay | Recipient Relay / setup |
|---|---|---|
| Older adult + family | Status synthesis, meds, appointments, handoffs | My day plain language; preferences; helpers |
| Mobility needs | Transport + schedule honesty | Mobility notes in My care |
| I/DD | Min-necessary; no invented status | Supported decision-making copy; invite trusted helpers only |
| ADRD / memory | Temporal “yesterday / previous shift”; no false certainty | Simple setup; resume; helper can assist with consent |
| DSP / direct care | Shift briefing; coverage; handoff | N/A as recipient |
| Family caregiver | “Evelyn’s care · Marcus · Family” not “acting for” | N/A |

## Criterion map

| ACL criterion | Product mapping |
|---|---|
| Dignity & choice | Recipient self-profile path; privacy explain; no browse caregivers |
| Privacy | Server authz; leave/revoke; zero-access gates |
| Accessibility | Click/tap Today accordions; keyboard; aria-expanded |
| Personalization | Role experience labels; recipient vs caregiver Relay tone |
| Care complexity | Status synthesis + evidence labels; correction propagation |
| Burden reduction | Grounded answers without re-explaining; since-last-visit |
| Human accountability | Confirm before consequential; schedule request ≠ clinic booked |
| Scheduling / transport | Intent restore + multi-turn slot confirm |
| Continuous communication | Coordination only with authorized helpers |
| Supplement human connection | Relay companion language; no legal-rep overclaim |

## Explicit non-goals

- No HIPAA-compliance marketing claim
- No diagnosis from caregiver reports
- No external SMS claim without configuration
